# Use of Super Intelligence (SI) / AI tools

Disclosure for the NASA Space Apps Challenge 2026, following the challenge's SI-use rules: where and how SI tools were used, for code, data, audio and video.

| Element | SI used? | How | Where it is marked |
|---|---|---|---|
| **Source code** (frontend, backend, tests, scripts) | Yes, assisted | Written with an AI coding assistant (Anthropic **Claude Code** and OpenAI **Codex**), directed, reviewed and tested by the team. Design decisions, validation fixes and data choices were made iteratively with the assistant. | This file; `README.md` (SI use section); `package.json` field `siDisclosure`; header comments in `src/main.tsx` and `backend/main.py` |
| **Documentation** (README, roadmap, this file, submission text) | Yes, assisted | Drafted with Claude Code and Codex and edited by the team. | This file |
| **Scientific results** (trends, slopes, p-values, FDR, maps, SPI, satellite cross-checks) | No | Computed by deterministic code (Theil–Sen, Mann–Kendall, Benjamini–Hochberg, permutation tests) from NASA and partner data at request time. Nothing is generated or invented. | Method notes in the app and README |
| **Derived data files** (`backend/ai/data/episodes.json`, `anchors.json`, `system1-config.json`) | No generative SI | Built by the project's own scripts from NASA POWER records (analog library) and fitted by the project's own logistic-regression code (System-1 parameters). | README (AI layer, validation sections) |
| **In-app AI features** | Yes, at runtime | *Laya* (open decision model, convaiinnovations/laya, Apache-2.0) scores resemblance between trend patterns. An optional language model (Anthropic Claude via the user's own key, or a small local Qwen model) writes plain-language explanations of skill-verified results. *Google DeepMind WeatherNext 2* is an AI weather model used for forecasts. | Generated text is labelled "AI-generated (SI)" in the interface; About/Sources dialog has a "Use of AI (SI) tools" section |
| **Demo video** | Recording + SI audio | The 30-second video edits footage from a screen recording of the real application; the end card and captions are rendered with HyperFrames, with AI coding assistance. It is not a continuous live interaction. The narration **voice in the 30-second demo is AI-generated locally with Kokoro-82M (`af_heart`)** from an AI-assisted script prepared with Codex. Legacy `demo/voiceover.py` supports ElevenLabs; it was not used for the 30-second demo. | Visible on-screen notice in the video; video and audio file metadata (`comment`, `description`); `demo/README.md` |
| **Images / logos** | No | The brand mark and favicon are original vector artwork. No NASA logos, flags, insignia or mission identifiers are used, contained, modified or generated. NASA appears only as a named data source. | — |
